# Схема бази FIRMS

Тут лежать файли SQL схеми `firms` для PostgreSQL 17 з PostGIS 3 і скрипт `restore.sh`. Файли SQL створюють порожні таблиці й функції, описані в [docs/database/README.md](../../docs/database/README.md). Дані в схему заливає `restore.sh` з пакета дампу.

| Файл | Що робить |
|---|---|
| `sql/00_extensions.sql` | Вмикає PostGIS і створює схему `firms` |
| `sql/01_tables.sql` | Створює таблиці |
| `sql/02_functions.sql` | Створює функції й подання, якими застосунок читає дані |
| `sql/03_indexes.sql` | Створює індекси |
| `restore.sh` | Розгортає пакет дампу: схема, дані, індекси, суми, перевірка кількості рядків |

## Порожня схема без даних

Порожню схему можна створити вже зараз, поки нема пакета. Функції тоді повертають нулі, і на них можна перевірити виклики з PHP. Команда для бази застосунку, з кореня репозиторію:

```bash
for f in parser/firmsdb/sql/0*.sql; do
  docker compose exec -T db psql -U we_charge -d we_charge -v ON_ERROR_STOP=1 < "$f"
done
```

Повторний запуск безпечний: файли перестворюють функції й не чіпають таблиць, які вже є.

## Схема з даними

Схему з даними будує `restore.sh` з пакета дампу. Як його запустити, сказано в розділі 1 [docs/database/README.md](../../docs/database/README.md).
